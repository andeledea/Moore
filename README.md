# MOORE
Control software for the INRiM Moore three-axis measuring machine.

This branch (`v2`) is a restart of the project. The plan, decisions and roadmap
are in [docs/next_steps.md](docs/next_steps.md).

The v1 code (C++ / wxWidgets, described in the thesis) is kept as a reference
in [legacy/](legacy/) and is also available as the tag `v1-thesis`.
Its build instructions are in [legacy/README.md](legacy/README.md); run `make`
from inside `legacy/`.
